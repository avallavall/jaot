# Credits

Credits are a **free usage quota** on JAOT — a soft signal of how much solving an organization is doing, not something you buy. Monetization is off by default (the hosted jaot.io instance is free), so there is no purchasing, billing, or subscription. A solve draws at least one credit; if you bring your own Anthropic API key, AI features run on your own account and draw no platform credits.

> **Self-hosting:** the credit quota and per-plan caps are platform settings you can raise (or effectively disable) from the admin panel. The paid-billing code exists but is dormant behind `MONETIZATION_ENABLED` (off).

## GET /api/v2/credits/balance

Get the current credit balance for your organization.

**Authentication:** Requires API key or JWT token.

### Response

| Field | Type | Description |
|-------|------|-------------|
| `credits_balance` | integer | Credits available in the current quota |
| `currency` | string | Organization's preferred display currency |

### Examples

<CodeTabs>
```python
import httpx

API_URL = "https://jaot.io/api/v2"
headers = {"Authorization": "Bearer ok_live_your_key_here"}

response = httpx.get(f"{API_URL}/credits/balance", headers=headers)
balance = response.json()
print(f"Credits: {balance['credits_balance']}")
```

```bash
curl "https://jaot.io/api/v2/credits/balance" \
  -H "Authorization: Bearer ok_live_your_key_here"
```

```javascript
const response = await fetch("https://jaot.io/api/v2/credits/balance", {
  headers: { "Authorization": "Bearer ok_live_your_key_here" },
});

const balance = await response.json();
console.log(`Credits: ${balance.credits_balance}`);
```
</CodeTabs>

### Response

```json
{
  "credits_balance": 950,
  "currency": "EUR"
}
```

## GET /api/v2/credits/transactions

Get credit transaction history for your organization.

**Authentication:** Requires API key or JWT token.

### Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `transaction_type` | string | -- | Filter by type: `execution`, `refund`, `adjustment` |
| `limit` | integer | 50 | Max results (1-100) |
| `offset` | integer | 0 | Number of results to skip |

### Response

Returns an array of transaction objects.

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Transaction ID (e.g. `"txn_a1b2c3d4"`) |
| `transaction_type` | string | Type of transaction |
| `credits_amount` | integer | Credits change (negative = deduction, positive = addition) |
| `balance_after` | integer | Credit balance after this transaction |
| `description` | string | Human-readable description |
| `reference_type` | string | Related entity type (e.g. `"solve"`) |
| `reference_id` | string | Related entity ID |
| `created_at` | string | ISO 8601 timestamp |

### Examples

<CodeTabs>
```python
import httpx

response = httpx.get(
    "https://jaot.io/api/v2/credits/transactions",
    params={"limit": 10},
    headers={"Authorization": "Bearer ok_live_your_key_here"},
)
transactions = response.json()
for tx in transactions:
    print(f"{tx['created_at']}: {tx['credits_amount']:+d} credits - {tx['description']}")
```

```bash
curl "https://jaot.io/api/v2/credits/transactions?limit=10&transaction_type=execution" \
  -H "Authorization: Bearer ok_live_your_key_here"
```

```javascript
const response = await fetch(
  "https://jaot.io/api/v2/credits/transactions?limit=10",
  { headers: { "Authorization": "Bearer ok_live_your_key_here" } }
);

const transactions = await response.json();
transactions.forEach((tx) => {
  console.log(`${tx.transaction_type}: ${tx.credits_amount} credits`);
});
```
</CodeTabs>

### Response

```json
[
  {
    "id": "txn_a1b2c3d4",
    "transaction_type": "execution",
    "credits_amount": -3,
    "balance_after": 947,
    "description": "Solver execution",
    "reference_type": "solve",
    "reference_id": "exe_9a1b2c3d",
    "created_at": "2026-02-19T10:05:12Z"
  }
]
```

## POST /api/v2/credits/calculator

Estimate the credits an optimization problem will draw from the quota, based on its size. This endpoint is **public** and does not require authentication.

> **Info:** The calculator is public — use it to gauge how heavy a problem is before running it.

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `num_variables` | integer | Yes | Total number of decision variables (0-100,000) |
| `num_integer_vars` | integer | No | Number of integer variables (default: 0) |
| `num_binary_vars` | integer | No | Number of binary variables (default: 0) |
| `num_constraints` | integer | No | Number of constraints (0-100,000, default: 0) |
| `time_limit_seconds` | number | No | Time limit in seconds (1-86400, default: 300) |

### Response

| Field | Type | Description |
|-------|------|-------------|
| `credits_required` | integer | Estimated credits the solve will draw |
| `breakdown` | object | Cost breakdown by component |
| `breakdown.base_cost` | number | Base cost (always 1) |
| `breakdown.variable_cost` | number | Cost from number of variables |
| `breakdown.mip_penalty` | number | Additional cost for integer and binary variables combined (sqrt scaling) |
| `breakdown.constraint_cost` | number | Cost from number of constraints |
| `breakdown.time_bonus` | number | Extra cost for time limits above 60s |

### Examples

<CodeTabs>
```python
import httpx

API_URL = "https://jaot.io/api/v2"

response = httpx.post(f"{API_URL}/credits/calculator", json={
    "num_variables": 100,
    "num_integer_vars": 50,
    "num_binary_vars": 20,
    "num_constraints": 80,
    "time_limit_seconds": 60,
})

estimate = response.json()
print(f"Estimated credits: {estimate['credits_required']}")
print(f"Breakdown: {estimate['breakdown']}")
```

```bash
curl -X POST https://jaot.io/api/v2/credits/calculator \
  -H "Content-Type: application/json" \
  -d '{
    "num_variables": 100,
    "num_integer_vars": 50,
    "num_binary_vars": 20,
    "num_constraints": 80,
    "time_limit_seconds": 60
  }'
```

```javascript
const response = await fetch("https://jaot.io/api/v2/credits/calculator", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    num_variables: 100,
    num_integer_vars: 50,
    num_binary_vars: 20,
    num_constraints: 80,
    time_limit_seconds: 60,
  }),
});

const estimate = await response.json();
console.log(`Estimated credits: ${estimate.credits_required}`);
```
</CodeTabs>

  "credits_required": 32,

    "mip_penalty": 16.73,

  }
